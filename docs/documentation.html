Install

  1. Download the APK from GitHub Releases. Each release lists a SHA-256 you can check.
  2. Open it on your phone. Android will ask you to allow installing apps from your browser or file manager. Allow it for that app only, and turn it off again afterwards.
  3. Google Play Protect may say the app is unrecognised. That is expected for a sideloaded alpha that is not on the Play Store. Choose "More details" and then "Install anyway" only if you are comfortable with that. The source is public.

To see which build you have, open Android Settings, Apps, Grimoire. The version should match the changelog.

What content is in the app

The app ships only content from the System Reference Document 5.1 (CC-BY-4.0) plus original content. Everything else you use is homebrew that you create or import. That is deliberate: it keeps the app and this repository safe to distribute. Details are on the license and content policy page.

Homebrew

Open the Homebrew tab to create content. There are builders for:

  • races and subraces
  • classes and subclasses
  • spells
  • items, including rarer magic items
  • monsters
  • feats and backgrounds
  • conditions

Features (the mechanical pieces, such as a resource, a passive bonus or an active ability) are built in a feature editor that the other builders share. Most builders have a Test button that shows what the content does before you save it.

Saved homebrew lives in the Compendium, under the Homebrew mode. Official mode only ever shows the bundled SRD content, so your homebrew never gets mixed into it. Packages mode lists packs you have installed.

Sharing with .grimoire-pack

A .grimoire-pack is a single file that carries homebrew from one Grimoire to another. There are three separate things, on purpose:

ActionWhat it makesWhere
Export HomebrewOne entry plus everything it needs.Compendium, Homebrew mode, on the entry.
Export PackageSeveral entries chosen together, plus everything they need.Compendium, Homebrew mode, Select then Create Package. Or Packages mode, Create Package.
Export CharacterA character file. It is not a pack.Character sheet menu.

Dependencies

If a subclass needs two spells and a condition, exporting the subclass includes them, and the review screen shows what you chose and what was added automatically. The file does not carry official SRD content, because the person importing already has it.

Importing

In the Homebrew tab choose import, and pick the file. You see a preview grouped by type first, with problems listed (a missing dependency, a duplicate id, an unsupported ruleset, a damaged file). Nothing is added until you confirm, and a pack is added all together or not at all.

Example packs

Each release includes four small original packs, labelled "(Demo)", that you can import to see how it works.

Character export and import

Export Character writes a Grimoire Character JSON file (format: grimoire-character, version 1). It holds the character, and the Custom Rule Profile attached to it, if any. Import Character is on the Characters tab and reads that file.

  • A character file does not bundle homebrew. If the character uses your homebrew, send the pack too, and import the pack first.
  • The export menu also offers PDF, Markdown and plain text. Those are readable copies for printing or sharing, and they are marked "not importable".

Custom Rule Profiles

A Custom Rule Profile is a named set of rule choices that you attach to a character, without changing anything for other characters. It sits on top of the campaign's rules. It can cover:

  • ability score cap, level cap, XP on or off, hit point mode, multiclassing on or off
  • how ability scores are generated, including point-buy budget, minimum and maximum
  • house rules such as feat rules at level-up, flanking, critical hits, and short and long rest length

A profile only applies to characters in the same game family it was made for. Find it under the Homebrew tab.

Campaign sync

A DM starts a campaign and shows a room code (and a QR code). Players on the same local network join with the code or by scanning the QR code. Sync is optional, and the app works fully without it. Read the privacy page before using it: it is not encrypted and has no password.

Current limitations

  • Android only. There is no iOS build.
  • Alpha software, so expect rough edges and please report them.
  • Reactive features and outcomes are shown as text. Grimoire does not resolve them automatically.
  • Homebrew is 5e-compatible only.
  • A character file does not include the homebrew it uses. Character and homebrew in one file is not built yet.
  • Only SRD 5.1 and original content ships in the app. Other content has to come in as homebrew.
  • Campaign sync is unencrypted, so use it on a network you trust.
