Feedback

The most useful thing you can do is try one design that generic tools cannot handle, and tell me where it breaks. A short, specific report helps far more than a long general one.

Even one design is plenty. I am not asking for promotion or support.

Where to send it

  • GitHub issue (public, with a form that asks for the points below): open an issue.
  • Email (private, if you would rather not post): feedback.grimoire@gmail.com.

What to include

The same six points work for a bug, a missing feature, or a design that would not fit.

  1. What you tried. The character, class, feature or pack you were building, in a sentence or two.
  2. What you expected. What you thought would happen.
  3. What happened. What you actually saw, including any error message word for word.
  4. How to reproduce it. The steps, from the screen you started on.
  5. Content involved. Which homebrew or pack, or which SRD entry. If you can, attach the .grimoire-pack or the character file. Check it first for anything private.
  6. A screenshot or short video. Optional, but it often saves several messages.

It also helps to say which build you have and what phone you are using. To find the version, open Android Settings, Apps, Grimoire. The build should match an entry on the changelog.

What happens next

I read everything. I will reply when I can, and I will ask before quoting or crediting anyone. If a report becomes a fix, the changelog will say which build has it.
